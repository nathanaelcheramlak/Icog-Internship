# 🥘 RecRecommendations

**RecRecommendations** is a recipe recommendation assistant that uses MeTTa for symbolic reasoning and an LLM to explain and tailor recipe suggestions based on a user's dietary preferences and available ingredients.

---

## Features

- Symbolic reasoning with MeTTa to filter recipes based on ingredient matches.
- LLM-powered responses to generate human-friendly and context-aware recommendations.
- Supports dietary preferences like vegan, vegetarian, and non-vegan.

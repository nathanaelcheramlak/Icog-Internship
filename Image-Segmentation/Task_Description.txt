Graph-Based Image Segmentation Using Union-Find (FH Algorithm)

The main goal of this assignment is to learn and apply the Union-Find (Disjoint Set Union) data structure in the context of the Felzenszwalb–Huttenlocher (FH) algorithm, a graph-based image segmentation technique. By implementing this algorithm, you will gain hands-on experience in how Union-Find efficiently clusters similar pixels into coherent regions, a foundational concept in many clustering and segmentation tasks.
